# Tracker v1.0.0

## Как пользоваться скриптом

1. Скчиваем Архив и распаковываем в удобное место;

2. Скачиваем лист Метрики-{целевой месяц} из вашей рабочей таблицы в формате .csv, перед этим, если у вас в колонках Ср.просмотренность и Ср.сдаваемость - только регулярные дз стоят проценты, а не числа вида `0.xx`, то надо поменять тип данных на `число`;

3. Кладем табличку в распакованную папку `tracker` строго рядом с фалом `main.py`;

4. Пеереименовываем таблицу в `data.csv`;

5. Запускаем main.py либо `двойным кликом`, либо через `IDE`, либо же `ПКМ` -> `Открыть с помощью` -> `Другое приложение` -> `Python`, тут на ваше усмотрение, что выбрать, скрипты запускать умеете, надеюсь;

6. При успешном выполнении в этой же папке появится файл result.txt, все проценты по вебинарам и дз подтягиваются автоматически из таблицы, середина/конец месяца определяются сами;

7. В случае возникновения сложностей - пишите [мне](https://vk.com/um_marat), с радостью помогу!

## Предупреждения

1. Перед отправкой рекомендую проверить корректность имени ученика, в таблице оно может быть на английском, код это не проверяет. Так же можете сверить результаты с оригинальной таблицей, при нахождении багов - пишите [мне](https://vk.com/um_marat);

2. Скрипт призван упростить вашу жизнь, но полагаться на него на все 100% не стоит, с этим буду работать, если дойдут руки до улучшений, планирую добавить еще пару видов отписок, в т.ч. и по ежемесячным активациям;

3. С предложениями по улучшению или фичами тоже пишите [мне](https://vk.com/um_marat).

## Как код формирует сообщение

1. Заходим в папку `.\tracker\src\infrastructure\tracking_factory\templates\` и открываем файл `tracking.txt`;

2. Код формирует сообщение по полям так: `{!приветствие}, {имя}, {!Снова я}, {!Зачем пишу}, {Результаты}, {!Совет}, {!Планы на месяц/остаток месяца}`, где:

- {!приветствие} - поле `!Приветствие` в `tracking.txt`;

- {имя} - берется из таблицы;

- {!Снова я} - поле `!Снова` в `tracking.txt`;

- {!Зачем пишу} - поле `!Промежуточные` и `!Итоговые` в `tracking.txt`, в зависимости от даты;

- {Результаты} - формирует код на основе таблицы;

- {!Совет} - поле `!отлично`, `!хорошо`, `!плохо` в `tracking.txt`, в зависимости от результата если >20% среднее число вебов или дз по всем предметам - хорошо, если >80% - отлично, инче - плохо.

## Как менять шаблоны скриптов

1. Заходим в папку `.\tracker\src\infrastructure\tracking_factory\templates\` и открываем файл `tracking.txt`;

2. Просто добавляйте/удаляйте строки в соответствующих разделах, если нужно, они берутся на рандом из каждого поля по одному.
